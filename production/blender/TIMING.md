# DARK MODE — серый черновик ролика (одним кадром, 30 с)

Сцена `DM_Oner` в Blender, 24 fps, кадры 1–720. Камера — `RIG_cam` (одна непрерывная траектория),
две «линзы» на ней: `CAM_desktop` (16:9, 1280×720) и `CAM_mobile` (9:16, 720×1280, та же траектория,
чуть уже угол). Маркеры на таймлайне Blender совпадают с таблицей ниже.

Склеек нет: миры сменяются только в кадрах, полностью закрытых предметом —
чёрный диск буквы O, чёрное горло динозавра → тёмный дым дрифта, колпак колеса, циферблат часов.
На стыках кадр до и после совпадает по тону (проверено попиксельно).

## Для Higgsfield
- Ролик режется на куски по 5 с (или по мирам), каждый кусок — видео-референс движения + первый/последний кадр
  из этого же рендера, чтобы соседние куски сходились без стыка.
- Удобные точки реза (кадр полностью закрыт, стык невидим): 2.8 с (O), 9.0 с (горло/дым), 14.0 с (колпак),
  17.6 с (стекло).
- Первый кадр для генерации — присланный макет главного экрана (`production/brand/hero-reference.png`).
